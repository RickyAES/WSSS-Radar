Data source & settings

This app displays only aircraft locations supplied by a real ADS-B / MLAT source. There is no simulated mode. Missing ground aircraft means the selected feed has not provided usable ground positions.

On Vercel, the optional companion /api/aircraft endpoint provides same-origin access. Direct providers require browser CORS permission.

Auto-refresh is approximately 60 seconds for Airplanes.live and 180 seconds for ADSB.lol or the proxy (subject to errors and quota). ADSB.lol lists 500 anonymous requests/day per IP. Refresh attempts respect the source's minimum interval.

Airport geometry is based on published CAAS runway threshold and end coordinates. The base map uses CARTO / OpenStreetMap online tiles. Airport positions and received ADS-B tracks are not for operational navigation or ATC.
